重要：修复多设备 Relay 错投

旧版把同组设备映射到同一控制入口，并用最后一个客户端地址接收回包，会造成设备标签与实际主机不对应。alpha.5 为设备和每次连接建立独立通道，并校验目标、来源和连接 token。

请配套更新观看端和被控端。旧新版 Relay 通道不混用，不会为了兼容再退回不安全广播。保留原网络和应用签名，不要卸载或重建入网身份。

键鼠与 App 窗口

默认只看。确认当前设备后点击 Enable control，再点击远端画面取得键盘焦点。Lock control 或 Ctrl+Alt+Esc 停止控制。主屏可控制；标注 view only 的应用窗口/副屏仍只允许观看。

静止画面不再因两秒没有新帧而失去控制，仍要求主机心跳有效和当前来源至少收到一帧。暂停、失联、切换来源未确认时继续锁住输入。

验证方法：依次连接 Studio、MacBook，切换两个标签并观察各自画面；关闭较前面的非活动标签不应跳到其他设备；Apps 选择真实窗口，不应串到另一台主机。

本次已验证

真实三节点 WebSocket 回归通过，覆盖两个本地客户端及反向连接。HO5 新版测试接收器通过真实 Relay 同时接收两台 Mac 的独立测试窗口，连续五轮像素检查分别保持蓝色与红色，最后观测解码帧数 39 / 23，没有互串。这不是所有控件的人工点验，也不是长期压力测试。

Studio 已安装主机经独立测试窗口接收点击和按键，应用窗口采集与解码通过。没有对用户其他应用注入输入。Android 真机反向投屏不在这个测试范围内。

部署与保留边界

两台 Mac 已通过签名兼容升级器升级 alpha.5。HO5 新二进制已经准备好，但服务切换被远程工具安全检查拦截，仍需在本机完成激活；下载包已包含新 GUI。Windows 只提供包，没有启动本机捕获或改动 UU。

Android 为原签名正式 APK，versionCode 6，ARM64，JNI 与 16KB 对齐检查通过；覆盖安装保留原身份。按需验证真机触控与网络，不把构建通过等同于每个平台全部真机功能通过。
