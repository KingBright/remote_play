正常打开就是原版界面

macOS、Linux、Windows 桌面包的默认入口已恢复到原 GPUI／yororen 产品界面，包含设备抽屉、紧凑控制胶囊及原有样式。不是打开一个演示控件，也不需要设置 gpui-preview 或其他预览开关。简化 egui 界面仅能显式选择为诊断用途。

启动时会检查正在运行的界面类型，防止新程序悄悄唤回旧的简化界面。升级前应退出旧 RemotePlay；不要同时运行两个共享同一设备身份的后台实例。

安装入口

macOS：沿用 RemotePlay.app 的固定签名和原应用位置；本包未经过 Apple 公证。不应为了升级重置录屏或辅助功能授权。已部署用户使用原有用户目录 Applications 中的程序。

Windows：解压整个 RemotePlay 文件夹，保留 bin 目录及许可证，启动 remoteplay-gui.cmd。它默认只观看，不开启本机捕获或自启动，不修改 UU、驱动或执行策略。替换旧安装时先退出旧程序，再覆盖原应用目录，不能只替换另一个临时目录却继续点击旧快捷方式。

Linux：此 x64 原生视频构建已在 HO5 验证，依赖包内 runtime-dependencies.txt 所列系统库（FFmpeg codec62/util60 和兼容 GPU）。它不是任意 Linux 发行版通用静态包，不会自动升级系统或驱动。

Android：alpha.8 为相同发布签名的 ARM64 APK，versionCode=9，可覆盖安装。保留原移动端界面和手势，不把桌面 GPUI 冒称 Android 实现。上传下载页不等于实体手机已安装；不要先卸载旧应用。

使用及安全边界

选择具体设备后查看或控制；来源菜单可选择显示器及主机支持的应用窗口。输入需明确启用，暂停、失焦、失联及等待新来源帧时仍有保护。窗口控制使用主机真实焦点，不是后台独立桌面。应用级主机能力按操作系统实际能力显示。

视频呈现保留原生资源通路，不用每帧 CPU 图片转换来填补界面。Windows 仍有一次明确 GPU 资源复制，不宣称全链路零拷贝。GPU 提交计数不等于显示器刷新或端到端延迟。

验收范围

三种桌面系统的 App、网络、客户端、主机库及原版 GUI 输入专项已执行；安装包验证实际主程序输出的默认渲染器和原生视频能力。此页不声称所有原有功能、所有网络环境、长时间运行和极致性能都已完成最终验收。设备上的部署状态与安装包状态分开记录。
