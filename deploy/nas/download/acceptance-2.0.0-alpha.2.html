安装顺序

先更新作为主机的 Mac，再更新 Android。不要用新版切源 UI 去验收旧版主机：两端需要配套协议。Android 正式签名包保持原应用 ID 与签名，可覆盖升级；不要先卸载，以免丢失本机入网身份。四台设备的共用网络不需要重新创建。

macOS 请退出旧程序后将新 Weavelo.app 放到原来的 ~/Applications。如果此前使用 launchd 后台服务，需先停止旧服务再替换文件，避免同一端口同时运行两个实例；不要启动新旧两个副本。按系统正常流程授予屏幕录制与辅助功能权限。

Windows 包是主机端安全候选，不含观看 GUI；本轮未启动 Windows 捕获，也未恢复自启动。UU 仍在使用时，不要直接同时开启两套串流做验收。Linux 包是 HO5 原生构建的主机端，不含观看 GUI，也不安装系统服务。

手机验收

  1. 覆盖安装后确认仍在原网络，查看成员列表，检查在线设备能力与路由提示是否真实。
  2. 连接 Mac，点击四角和中心；在 1x 下双击远端文件、长按右键、双指滚动。确认没有同时触发本地缩放。
  3. 双指捏合到 2x 或 3.5x，再平移、点击小图标；两指错时抬起不能产生远端误点。RESET 只复位本地视口。
  4. 放大后切横竖屏，确认阅读中心稳定、黑边不接收远端点击。暂停后可本地缩放，但不能用触摸或虚拟键操作远端。
  5. 展开 Tools 和 KEYS，锁定 Ctrl/Shift 再点击普通键，检查组合键；隐藏键栏、打开设置、暂停或退出时不得遗留按下状态。
  6. 应用进入后台后返回，检查恢复、画面方向、音频和文件传输。记录机型、系统版本、主机版本、路径 LAN/P2P/Relay 及复现步骤。

Mac GUI 验收

  1. 连接并全屏：顶部 16px 感应区唤出工具条，离开后延迟隐藏；胶囊两侧能点击远端菜单，工具条与菜单上的操作不能泄漏到远端。
  2. 有真实副屏时显示其按钮，没有则不应伪造 Display 2；Apps 列表使用实际可用窗口。
  3. 连续切换主屏、副屏和应用窗口，核对名称、回执与新画面；只读来源必须显示只读。回执表示请求被接受，不等于新画面首帧已经显示。
  4. 暂停中切源、主机关掉被选窗口、暂时断网再恢复：应有明确状态，不能遗留永久 Connecting 或意外恢复输入。

已知范围

14 项 Android 设备交互测试已经编译；上一轮模拟器启动 ANR，不能当作真机通过。本轮主要提供正式签名 APK、匹配 JNI、可校验的桌面产物和定向自动化回归。实体手机 SurfaceView/MediaCodec 的实际像素与触点一致性、多显示器首帧长稳及 Windows/UU 共存仍需实测。

当前软键盘按键通道主要覆盖 ASCII 与常用控制键。保留 IME 组合态不等于完整支持中文、emoji 或任意 Unicode 注入；不要把原设计稿中的示例数据、虚拟游戏手柄、iOS 客户端或全平台 GUI 视为本版已交付功能。
